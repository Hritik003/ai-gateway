Key Components

  • MCPRoute — Custom resource defining MCP server routes and OAuth configuration
  • MCPRouteController — Reconciles MCPRoute into HTTPRoute + Backend with dummy IP 192.0.2.42
  • Envoy Gateway — Translates Gateway API resources into Envoy xDS configuration
  • Extension Server — Intercepts xDS before delivery; rewrites MCP clusters to 127.0.0.1:9856
  • MCP Proxy — Local sidecar on port 9856; handles MCP JSON-RPC and serves OAuth metadata
  • ai-eg-mcp-main- — Cluster name prefix used to identify MCP proxy clusters (internalapi.MCPMainHTTPRoutePrefix)
  • 192.0.2.42 — RFC 5737 TEST-NET-2 dummy IP; never routable, used as a placeholder for the extension server to rewrite
  • x-ai-eg-mcp-oauth-metadata-type — Header set by HTTPRoute filter to tell the MCP proxy which OAuth metadata to serve (protected-resource or authorization-server)
  • Path-based issuer — When oauth.issuer.path is set, metadata requests are proxied to the MCP Proxy which dynamically builds full URLs from the Host header
  • URI-based issuer — When oauth.issuer.url is set, metadata is served via DirectResponse HTTPRouteFilters with static JSON baked at controller time (not shown in data-plane diagram above)
